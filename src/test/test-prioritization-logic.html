API Text 优先级逻辑测试

测试说明

本页面用于测试 apiText 参数优先级逻辑：

  • ✅ 如果URL中存在 apiText 参数且能成功解析，优先使用apiText进行表单回填
  • ⚠️ 如果URL中没有 apiText 参数或解析失败，则使用 id 查询历史记录详情进行回显
  • 📝 支持同时存在 apiText 和 id 参数的情况

测试场景

测试场景 URL参数 期望行为 操作
场景1：仅有apiText apiText=... 使用apiText回填，不查询服务器
场景2：仅有id id=xxx 查询服务器历史记录进行回显
场景3：同时有apiText和id apiText=...&id=xxx 优先使用apiText，忽略id查询
场景4：apiText格式错误 apiText=invalid&id=xxx fallback到id查询
场景5：无参数 无 显示默认表单
